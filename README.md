# NEW UNIKIDS APP

Student and Teacher Android learning management application.

## Technology
- Kotlin
- Jetpack Compose
- Google Apps Script backend (integration phase)
- Google Sheets database (integration phase)
- Google Drive media storage (integration phase)
- GitHub Actions Android APK build
- No Firebase
